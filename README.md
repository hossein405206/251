# پروژه 251 | طلبه، ادیتور، برنامه‌نویس

وب‌سایت فارسی راست‌چین برای معرفی خدمات و ثبت درخواست پروژه. ظاهر واکنش‌گراست و برای موبایل هم طراحی شده است.

## فایل‌ها
- `index.html`: سایت و فرم ثبت پروژه
- `Code.gs`: بک‌اند Google Apps Script برای ذخیره درخواست‌ها در Google Sheets

## راه‌اندازی ذخیره درخواست‌ها (Google Apps Script)

1. یک Google Sheet جدید بساز.
2. از منوی **Extensions → Apps Script** وارد ویرایشگر شو.
3. محتوای فایل `Code.gs` این مخزن را در فایل پیش‌فرض `Code.gs` کپی کن و ذخیره کن.
4. از فهرست توابع، `setup` را انتخاب و یک بار **Run** کن؛ دسترسی لازم را تأیید کن. یک برگه به نام **Project Requests** و سرستون‌ها ساخته می‌شود.
5. در Apps Script روی **Deploy → New deployment** بزن.
6. نوع را **Web app** انتخاب کن؛ گزینه **Execute as** روی **Me** و **Who has access** روی **Anyone** باشد. سپس Deploy را بزن.
7. نشانی وب‌اپ که به `/exec` ختم می‌شود کپی کن.
8. در `index.html` مقدار `SCRIPT_URL` را از `PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE` به نشانی واقعی خودت تغییر بده و تغییر را در GitHub ثبت کن.

> آدرس Web App را داخل `index.html` قرار بده، نه کد مخزن را به‌عنوان رمز محرمانه در نظر بگیر. چون فرم عمومی است، ممکن است اسپم دریافت کند؛ برای انتشار گسترده بهتر است محدودیت نرخ و کنترل ضداسپم اضافه شود. به کاربران وعدهٔ محرمانگی مطلق نده و دسترسی Google Sheet را فقط برای خودت نگه دار.

## انتشار رایگان با GitHub Pages

1. وارد تنظیمات مخزن GitHub شو.
2. بخش **Pages** را باز کن.
3. در بخش Build and deployment، گزینه **Deploy from a branch** را انتخاب کن.
4. شاخه `main` و پوشه `/(root)` را انتخاب و Save کن.
5. پس از پایان انتشار، لینک سایت در همان بخش نمایش داده می‌شود.

ممکن است چند دقیقه طول بکشد تا سایت فعال شود.

## تصویر پروفایل

سایت از لینک مستقیم فایل Google Drive استفاده می‌کند. مطمئن شو فایل عکس روی **Anyone with the link / هرکسی پیوند را دارد** تنظیم شده است. اگر عکس نمایش داده نشد، تصویر را در مخزن با نام `profile.jpg` قرار بده و مقدار `src` تصویر را به `profile.jpg` تغییر بده.

## نکتهٔ مهم دربارهٔ فرم

نسخهٔ فعلی فرم از درخواست `no-cors` استفاده می‌کند تا با محدودیت‌های مرورگر در پاسخ Google Apps Script درگیر نشود. به همین دلیل مرورگر نمی‌تواند نتیجهٔ واقعی نوشتن در شیت را تأیید کند؛ پیام موفقیت یعنی درخواست ارسال شده، نه تضمین قطعی ذخیره‌شدن. پس از تست، شیت را بررسی کن. برای نیازهای جدی‌تر بهتر است بک‌اندی با پاسخ قابل‌تأیید و کنترل ضداسپم راه‌اندازی شود.
