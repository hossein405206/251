# پروژه 251 | طلبه، ادیتور، برنامه‌نویس

سایت فارسی راست‌چین معرفی خدمات و ثبت پروژه، همراه با Google Sheets برای ذخیره درخواست‌ها و پنل مدیریت خصوصی در Google Apps Script.

## فایل‌ها
- `index.html`: صفحهٔ اصلی، خدمات، فرم ثبت پروژه، راه‌های تماس و معرفی رسانهٔ مهدی موعود
- `Code.gs`: بک‌اند ثبت درخواست‌ها و توابع پنل مدیریت
- `Admin.html`: رابط پنل مدیریت (باید به‌عنوان فایل HTML در خود Apps Script هم ایجاد شود)

## مهم: پروژهٔ ۳۱۳ را دست نزن
برای ۲۵۱ یک Google Sheet و یک پروژهٔ مستقل Apps Script بساز. کدهای ۲۵۱ را داخل پروژهٔ Apps Script مربوط به ۳۱۳ نریز؛ هر دو پروژه در یک محیط Apps Script می‌توانند نام توابع مشترک مثل `doGet` و `doPost` داشته باشند و با هم تداخل کنند.

## راه‌اندازی بک‌اند و پنل مدیریت
1. یک Google Sheet جدید مخصوص پروژهٔ ۲۵۱ بساز.
2. از همان شیت، Extensions → Apps Script را باز کن. این باید یک پروژهٔ Apps Script جدید و مستقل باشد.
3. فایل پیش‌فرض `Code.gs` را با محتوای فایل `Code.gs` این مخزن جایگزین کن.
4. در ویرایشگر Apps Script روی + کنار Files بزن و **HTML** را انتخاب کن؛ نام فایل را دقیقاً `Admin` بگذار (پسوند را خود Apps Script اضافه می‌کند). محتوای `Admin.html` مخزن را در آن کپی کن.
5. در تنظیمات پروژه (Project Settings) بخش **Script properties** یک ویژگی بساز:
   - Property: `ADMIN_PASSWORD`
   - Value: یک رمز طولانی، یکتا و غیرقابل حدس که در جای امن نگه می‌داری.
   این رمز را در GitHub یا داخل فایل‌های HTML ننویس.
6. تابع `setup` را یک بار اجرا کن و دسترسی‌ها را تأیید کن. این تابع شناسهٔ شیت را ذخیره می‌کند و برگهٔ Project Requests و ستون‌های آن را می‌سازد.
7. Deploy → New deployment → Web app را انتخاب کن:
   - Execute as: **Me**
   - Who has access: **Anyone** (برای اینکه فرم عمومی کار کند)
   سپس Deploy را بزن و URL تمام‌شده با `/exec` را کپی کن.
8. در فایل `index.html` مقدار `SCRIPT_URL` را با URL واقعی Web App جایگزین کن و تغییر را در GitHub ثبت کن.
9. پنل مدیریت در URL وب‌اپ با افزودن `?admin=1` باز می‌شود؛ نمونه: `YOUR_WEB_APP_URL/exec?admin=1`. رمز مدیر همان مقدار `ADMIN_PASSWORD` است.
10. یک پروژهٔ آزمایشی ثبت کن و بررسی کن که در برگهٔ Project Requests ذخیره شده باشد. بعد با پنل مدیریت وضعیتش را تغییر بده و تست کن.

## انتشار سایت با GitHub Pages
1. وارد مخزن GitHub شو و Settings → Pages را باز کن.
2. در Build and deployment، گزینهٔ Deploy from a branch را انتخاب کن.
3. شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب و Save کن.
4. پس از پایان انتشار، نشانی سایت در همان بخش نمایش داده می‌شود.

## نکات امنیتی و محدودیت‌ها
- شیت Google Sheets را عمومی نکن؛ فقط حساب خودت باید به آن دسترسی داشته باشد.
- رمز مدیر فقط در Script Properties ذخیره شود. توابع مدیریت رمز را سمت سرور بررسی می‌کنند؛ با این حال، پیش از انتشار عمومی، تنظیمات دسترسی و عملکرد را آزمایش کن.
- فرم عمومی است و ممکن است اسپم دریافت کند. honeypot کمک اولیه است، نه محافظت کامل در برابر اسپم.
- فرم فعلی از `fetch(..., mode: "no-cors")` استفاده می‌کند؛ مرورگر نمی‌تواند پاسخ واقعی Apps Script را بخواند. بنابراین پیام صفحه صرفاً نشان می‌دهد درخواست از مرورگر ارسال شده و تضمین قطعی ذخیره‌شدن نیست. حتماً شیت را پس از آزمایش بررسی کن.
- اطلاعات تماس مشتریان را خصوصی نگه دار و فقط برای پیگیری درخواست استفاده کن.
- در هر فایل، قبل از انتشار تغییرات مهم را آزمایش کن.
